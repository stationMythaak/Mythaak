✅ الطريقة 1: مباشرة بلا Cloud Console (ساهلة)

  1. حل script.google.com ← مشروع جديد
  2. انسخ والصق محتوى ملف Drive-AppsScript-Code.gs اللي مع التطبيق
  3. دير Deploy ← New deployment ← Web app ← Execute as: Me ← Access: Anyone ← انسخ الرابط
  4. الصق الرابط هنا لتحت 👇

⚙️ الطريقة 2: OAuth متقدمة (Cloud Console)
  1. أنشئ مشروع في Google Cloud Console وفعّل Drive API
  2. أنشئ OAuth Client ID (Web) وأضف origin موقعك
  3. الصق الـ Client ID هنا ثم سجّل الدخول
